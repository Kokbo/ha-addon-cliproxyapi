# Home Assistant App: CLIProxyAPI

![Supports aarch64 Architecture][aarch64-shield]
![Supports amd64 Architecture][amd64-shield]
![Upstream version][upstream-shield]

Runs [router-for-me/CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI)
on Home Assistant: an OpenAI- and Claude-compatible HTTP API on port `8317`
for your Claude Code, Codex, Gemini, Grok/xAI and other OAuth subscriptions,
with a web terminal in the sidebar for logging in to providers.

The image is built on your device from upstream source; the first install
takes several minutes. See the **Documentation** tab for setup and security.
